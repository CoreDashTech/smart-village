# CoreDash Village

ระบบบริหารหมู่บ้านจัดสรร (PWA ไม่ต้องมีเซิร์ฟเวอร์) โดย CoreDash Technology

โมดูล: ภาพรวม · ค่าส่วนกลาง/ค้างชำระ · น้ำ-ไฟ-ขยะ · จองสระ/ฟิตเนส · รถขยะ & งานส่วนกลาง · รถเข้า-ออก (บันทึกทะเบียน+รูป+ประทับเวลา, e-pass QR) · จอดริมถนน & ค่าปรับ (เข้ากองกลาง) · การเงิน/งบดุล (เดือน/ไตรมาส/ปี) · ประกาศ/แจ้งซ่อม/โหวต · ทะเบียนบ้าน · ตั้งค่า (สีพื้นหลัง/แถบซ้าย/สีหลัก, รูปปก 16:9)

## ขึ้น GitHub Pages (repo ชื่อ `smart-village`)
1. สร้าง repo ใหม่ใน CoreDashTech ชื่อ `smart-village` (Public)
2. แตกซิปนี้ แล้วอัปโหลด **เนื้อในโฟลเดอร์** (index.html, assets, sw.js ฯลฯ) ไปที่ root ของ repo
3. Settings → Pages → Branch `main` / `/ (root)` → Save
4. รอ 1–2 นาที เปิด https://coredashtech.github.io/smart-village/

## หมายเหตุ
- ตอนนี้เป็นข้อมูลตัวอย่าง ไปที่ ตั้งค่า → “ล้างข้อมูลทั้งหมด” เมื่อจะใช้จริง
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่อง ควรเชื่อม Google Sheet หรือดาวน์โหลดข้อมูลสำรองสม่ำเสมอ (ดู SETUP-GoogleSheet.md)
- รถเข้า-ออก: บันทึกทะเบียนด้วยมือ/ถ่ายรูป ยังไม่ใช่กล้องอ่านทะเบียนอัตโนมัติ (LPR)
- ค่าปรับจอดรถ ต้องมีข้อบังคับ/มติที่ประชุมใหญ่รองรับก่อนเก็บจริง
